Sekarang tinggal 3 langkah lagi:

───────────────────────────────────────────────────────────────────
STEP 1: BUAT REPOSITORY DI GITHUB
───────────────────────────────────────────────────────────────────

1. Buka browser, masuk ke: https://github.com/new

2. Isi form:
   - Repository name: inventoryobat (atau nama lain)
   - Description: Sistem Manajemen Inventaris Apotek
   - Public atau Private: Pilih sesuai keinginan
   - ❌ JANGAN centang "Add a README file"
   - ❌ JANGAN centang ".gitignore"
   - ❌ JANGAN pilih license

3. Klik tombol "Create repository"

4. GitHub akan menampilkan halaman dengan instruksi.
   COPY URL repository yang muncul, contoh:
   https://github.com/username/inventoryobat.git

   (Ganti 'username' dengan username GitHub Anda!)

───────────────────────────────────────────────────────────────────
STEP 2: LINK DAN PUSH KE GITHUB
───────────────────────────────────────────────────────────────────

Jalankan 2 command ini di terminal (satu per satu):

# 1. Link ke repository GitHub (GANTI URL dengan milik Anda!)
git remote add origin https://github.com/USERNAME/inventoryobat.git

# 2. Push ke GitHub
git push -u origin main


CONTOH LENGKAP:
--------------
Jika username GitHub Anda: johndoe
Maka command-nya:

git remote add origin https://github.com/johndoe/inventoryobat.git
git push -u origin main

2. Klik tab "Settings"
3. Scroll ke bawah, klik "Pages" di sidebar kiri
4. Di bagian "Source", pilih: "GitHub Actions"
5. Save (otomatis)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ ERROR: "remote origin already exists"
   → Jalankan: git remote remove origin
   → Lalu ulangi: git remote add origin URL_ANDA

❌ ERROR: Permission denied
   → Pastikan Anda sudah login ke GitHub
   → Atau gunakan Personal Access Token

❌ 404 Not Found setelah deploy
   → Tunggu 2-3 menit lagi
   → Pastikan Pages source = GitHub Actions
   → Refresh browser

❌ Build failed di Actions
   → Check logs di tab Actions
   → Pastikan secrets sudah benar

❌ Tidak bisa login
   → Pastikan user sudah dibuat di Supabase
   → Check email dan password
